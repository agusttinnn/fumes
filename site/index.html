fumes — a lightweight Steam client for the terminal

Install, update and play your Steam games without the Steam UI. fumes downloads games straight from Steam's content servers and runs them with Valve's own Steam client engine, so games still get the real Steamworks API: ownership, achievements, cloud saves, friends and multiplayer.

Download Source on GitHub

What it does

  • Your whole Steam library in a terminal UI: search, favorites, install, update, verify and uninstall.
  • Resumable downloads that only fetch what changed, using the same protocol as the Steam client.
  • Steam Cloud saves come down before you play and go up after, with a prompt when local and cloud saves conflict.
  • Friends and chat: see who's online and what they're playing, send messages, join friends' games and send invites.
  • Small footprint: one program, plus only the Steam engine (about 100 MB on macOS instead of ~400 MB for the full client).
  • Works alongside Steam: games installed by the official client are listed and launch too.

Getting started

Run fumes with no command to open the terminal UI, or use the commands directly:

fumes login                    # account name, password, then Steam Guard
fumes library                  # everything you own
fumes install "san andreas"    # by app id, exact name, or part of the name
fumes engine setup             # macOS, once: lets games find the engine
fumes launch "san andreas"
fumes sync "san andreas"       # pull Steam Cloud saves without playing

Your password never touches disk: only Steam's refresh token is kept, readable by your user alone.

Status

fumes is young. Cloud sync on launch currently works on macOS only, Linux and Windows haven't been tested at runtime yet, and beta branches aren't supported. See the full list of limits.

Third-party clients are a grey area under the Steam Subscriber Agreement. fumes only downloads games your account owns, and downloads Valve's engine from Valve's servers rather than redistributing it.
